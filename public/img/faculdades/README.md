# Imagens das faculdades

Coloque aqui um arquivo `.png` para cada faculdade. O nome do arquivo deve ser o
`nome_faculdade` cadastrado no sistema, em minúsculas, sem acentos e com espaços
trocados por hífen.

Exemplos:
- `FMU` -> `fmu.png`
- `Unitri Integral` -> `unitri-integral.png`
- `Braz Cubas` -> `braz-cubas.png`

Se o arquivo não existir, o site mostra automaticamente um ícone com as iniciais
da faculdade no lugar da imagem — nenhuma outra configuração é necessária.
